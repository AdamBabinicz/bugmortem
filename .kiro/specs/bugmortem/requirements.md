# BugMortem: Requirements Document

## 1. Objective
A cyber-gothic forensic incident autopsy studio that investigates software crashes, reconstructs crash timelines, pinpoints the root cause, generates immediate code patches, and produces enterprise-grade post-mortem reports.

## 2. Target Category
Kiroween Hackathon 2026 - Costume Contest / Spooky Developer Tools.

## 3. Core Features
- Digital Autopsy Engine: Analyzes raw stack traces, error logs, and runtime exceptions.
- Interactive ECG Vital Signs: Real-time visual flatline indicator for dead services that revives upon applying patches.
- Forensic Death Timeline: Chronological step-by-step breakdown of events leading to the crash.
- Instant Resurrection Patch: Side-by-side diff view of vulnerable code vs fixed code with one-click copy.
- Architecture Blast Radius Heatmap: 5-tier microservice topology map (Client SPA, Edge Gateway, Auth, Database, Worker Pool) isolating Patient Zero with reactive recovery transitions.
- Live Chaos Engineering Sandbox: In-browser fault injection simulating latency spikes, DB pool exhaustion, heap OOM leaks, and auth storms with live telemetry gauges (RPS, p99, error rate).
- Multi-Platform On-Call Dispatcher: Standardized escalation payloads for Slack / Discord War Rooms, PagerDuty (CEF v2 JSON), and prefilled GitHub Issues.
- SRE Forensic Coroner Voice Verdict: Browser-native speech synthesis delivering spoken forensic findings in an authoritative coroner tone (localized in EN and PL).
- Cyber-Gothic Death Certificate (PDF): Client-side printable hospital-grade outage certificate with official seal and stack trace biopsy.
- Post-Mortem Report Generator: Standardized SRE incident documentation ready for Markdown export.
- 6 Canonical SRE Horror Presets: One-click reproduction of infamous production disasters (Hydration, Connection Pool, OOM Reaper, Retry Storm, CORS Preflight, Serverless Cold Start Timeout).

## 4. Architectural & Quality Invariants
- Zero External Multimedia Assets: 100% procedural Web Audio API synthesis (0 KB download footprint).
- Local-First Data Sovereignty: All crash dumps, stack traces, and code snippets parsed strictly in client browser memory (Google Consent Mode v2 enforced).
- Property-Based Testing (PBT): Formally verified invariants via Vitest and fast-check (33/33 tests passing).
- Full Bilingual i18n: 100% tokenized UI strings across English and Polish with typographic orphan fixing.
